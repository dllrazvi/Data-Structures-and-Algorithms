                            # 📚 Course Overview
Throughout the course, I worked with essential data structures and core algorithms, learning how to implement and apply them in C/C++.

Main topics covered:

Arrays, vectors, and basic sorting/searching algorithms

Stack and queue abstract data types (ADTs), both static and dynamic

Singly and doubly linked lists, circular lists, advanced list operations

Binary trees and binary search trees (BST), including traversals

Introduction to hashing and efficient data access

Basic principles of algorithmic complexity (Big O notation)

                            # 💡 What I Learned
Practical coding skills to implement and manage fundamental data structures

How to approach problems using the right algorithm or structure

Manual memory management using pointers and dynamic allocation in C

Writing modular and clean code, splitting logic across multiple files

Debugging and optimizing code for both correctness and performance

Analytical thinking to compare solutions and understand trade-offs

                          # 🎯 Beyond the Basics
In addition to mandatory tasks, I solved many extra exercises to:

Explore alternative implementations (e.g., different sorting strategies)

Tackle real-world inspired problems (e.g., queue simulations, recursive tree problems)

Consolidate both theoretical and applied knowledge through hands-on coding
